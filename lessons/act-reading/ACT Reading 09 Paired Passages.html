What is it?

What is a paired-passage set?

A / B / both · 先定范围

A paired set contains two related texts. Questions may ask about A, B, or both.

A: Exercise can improve mood.
B: Walking with friends can reduce stress.

只问 A 的题不能借用 B 的细节；问 both 时必须分别找到两篇支持。原卷与新版题号数量可能不同，以题干为准。

Shared topic ≠ same view · 同题不同重点

Both texts discuss a benefit of physical activity. A focuses on mood generally; B gives a social example.

How to approach it

A reading order that helps

1

Read Passage A, then answer the A questions

While A is fresh, answer the questions that ask only about A. 先读 A,做只问 A 的题。

2

Write one line about A

Topic + focus + approach. Example: “Why Guy matters to film history — general, academic.” 用一行写下 A 的话题、重点、写法。

3

Read Passage B, then answer the B questions

As you read, compare: Does B agree with A? Add a new angle? Give an example? 读 B 时和 A 比较:同意?补充?举例?

4

Answer the “both” questions last

For each choice, check Passage A and Passage B separately. A “both” answer must be true in both. 最后做两篇题;每个选项都要在 A、B 中分别核对。

Wrong answers

How wrong answers are built in “both” questions

True of only one passage

The most common trap. The detail is real, but it appears in only A or only B.

只在一篇中出现。

Reversed

“Prominent in A but absent in B” — the choice describes something in B but not A.

方向反了:A 有 B 无 ↔ B 有 A 无。

Not in either

Sounds like the topic, but neither passage says it.

两篇都没提。

Wrong description of approach

For “perspective” or “approach” questions: wrong person (I / she) or wrong tense (present / past).

写法题:人称或时态判断错。

Summary

What to remember about paired passages双篇题要点

Identify the question scope

Passage A and Passage B share a topic. Questions are labeled: A only, B only, both.

先看题目只问 A、只问 B，还是 both。

Use a reading order

Order: read A → answer A; read B → answer B; then answer the both questions.

先各自读懂，再比较；顺序可按自身效率调整。

Summarize each passage

After each passage, write one line: topic + focus + approach (personal? academic? past? present?).

分别写下话题、重点与写法。

Check both passages

For “both” questions, check every choice in each passage separately.

both 的答案必须在两篇中分别成立。

Avoid one-sided evidence

The most common trap: a true detail that appears in only one passage.

只有一篇支持的细节不能当作共同点。

30-second check · 30 秒自检

Name the skill, cite the evidence, and explain why one wrong choice fails.

说出本课规则／方法，指出依据，并解释一个错误选项为什么错。
