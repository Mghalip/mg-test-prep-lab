Concept

What is an inequality? · 什么是不等式

Symbols and words 符号与词语

SymbolRead asWords on the SAT中文
x < 5less thanfewer than, below小于
x > 5greater thanmore than, above, exceeds大于
x ≤ 5less than or equal toat most, no more than, maximum至多，不超过
x ≥ 5greater than or equal toat least, no less than, minimum至少，不少于
3 ≤ x ≤ 8between 3 and 8from 3 to 8介于两数之间

“at most / maximum”用 ≤；“at least / minimum”用 ≥。注意 “no more than” 是 ≤，不是 >。

Many solutions 解有很多个

An equation x + 2 = 7 has one answer. An inequality x + 2 > 7 has many: every number greater than 5.

Is 6 a solution of x + 2 > 7? 8 > 7 ✓ yes. Is 5? 7 > 7 ✗ no.

On a number line: x > 5 → open circle at 5 (5 not included), arrow right. x ≥ 5 → closed (filled) circle at 5.

“You must be at least 16 to drive.” → a ≥ 16. Age 16 is allowed.

不等式的解是一个范围。> 和 < 不包括端点（空心圈），≥ 和 ≤ 包括端点（实心圈）。

Concept

Solving an inequality · 解不等式（何时变号）

Same as an equation… 和解方程一样

3x − 4 < 11

  1. Add 4: 3x < 15
  2. Divide by 3 (positive): x < 5
  3. Test x = 0: −4 < 11 ✓ (0 is less than 5, so it should work).

…except: flip the sign when you multiply or divide by a negative number.

−2x + 7 ≥ 1

  1. Subtract 7: −2x ≥ −6
  2. Divide by −2 → flip: x ≤ 3
  3. Test x = 0: 7 ≥ 1 ✓; test x = 4: −1 ≥ 1 ✗ — good, 4 is not ≤ 3.

乘或除以负数时，不等号方向要反过来；加减任何数都不用变号。

Why flip? 为什么变号

2 < 5 is true. Multiply both sides by −1: −2 and −5. Now −2 > −5, so the sign must turn around.

❌ −3x > 12 → x > −4Divided by −3 but forgot to flip.

✅ −3x > 12 → x < −4

Whole-number answers 取整

An 80 kg worker loads 12 kg boxes into an elevator with a 450 kg limit. Most boxes?

80 + 12b ≤ 450 → 12b ≤ 370 → b ≤ 30.8… → 30 boxes (round down; 31 boxes would be too heavy).

求“最多”向下取整，求“至少”向上取整，因为人数、箱数必须是整数。

Concept

Two-variable inequalities and graphs · 二元不等式的图像

Shade one side of the line 画阴影

y ≥ 2x − 1

  1. Draw the line y = 2x − 1. Solid line for ≥ / ≤ (the line is included); dashed for > / <.
  2. Test a point not on the line, usually (0, 0): 0 ≥ 2(0) − 1 → 0 ≥ −1 ✓ true.
  3. So shade the side that contains (0, 0) — here, above the line.

Rule of thumb: y > or y ≥ → above; y < or y ≤ → below (when y is alone on the left).

先画边界线（含等号用实线，不含用虚线），再代入 (0, 0) 判断阴影在哪一侧。

Is a point a solution? 判断点是否为解

Is (2, 1) a solution of the system y > x − 3 and y < −x + 2?

  1. First: 1 > 2 − 3 = −1 ✓
  2. Second: 1 < −2 + 2 = 0 ✗
  3. One inequality fails → not a solution.

The solution of a system of inequalities is the overlap of the shaded regions.

Desmos: type y>x-3 and y<-x+2, then the point (2,1). Is it inside both shadings?

把点代入每一个不等式，全部成立才是解；不等式组的解是阴影重叠部分。

Key facts

The language and the rules不等式的语言和规则

at most / no more than / maximum / within budget
至多／不超过
≤
例：最多 20 人 → n ≤ 20；20 本身允许取到。
at least / minimum / no less than
至少／不少于
≥
例：至少 18 岁 → a ≥ 18；18 本身允许取到。
between a and b
在两数之间
a ≤ x ≤ b
含端点：2 ≤ x ≤ 5；若明确不含端点，则写 2 < x < 5。
“the minimum value of x is m”
最小值
x ≥ m (every value is at least m)
例：最小值为 4 → x ≥ 4；4 是允许的最小数，不是唯一值。
Flip the sign
乘除负数要反向
−2y > 4 → y < −2 (divided by a negative)
例：−2y > 4，两边除以 −2 → y < −2；仅加减负数不用反向。
Test a point
代入检验
substitute (x, y); it is a solution only if every inequality is true
例：(1, 3) 满足 y > x + 1，因为 3 > 2；方程组需逐条检查。
Graph of y > mx + b
边界与阴影
region above the line (dashed line for >, solid for ≥)
大于选直线上方；小于选下方。严格不等号用虚线，含等号用实线。
Budget model
预算上限
fixed cost + (rate × number) ≤ budget
例：固定费 10、每件 3、预算 25 → 10 + 3n ≤ 25，最多 5 件。

When the answer must be a whole number (attendees, boxes, candles), solve, then round down for a greatest value and up for a least value. 人数、箱数等取整：求最大值向下取整，求最小值向上取整。

How to approach it

Steps

1

Write the quantity, then compare it with the limit

Combined weight 500 + 120b, which is “no more than 4,600” → 500 + 120b ≤ 4,600. 先写出总量，再与上限/下限比较。

2

Solve like an equation

Flip the inequality sign only when multiplying or dividing by a negative number. 像解方程一样，乘除负数时变号。

3

Check points or tables

Substitute each pair into all the inequalities. One false → not a solution. 代入每一个不等式，有一个不成立就排除。

Desmos: type inequalities directly, e.g. y>4x+8; the shaded region is the solution. Type the test point (14,0) to see whether it lies in every shaded region. Desmos 直接输入不等式，看点是否在所有阴影区域内。

Idea · 思路

Let s = small, L = large. To fit the most large candles, buy as few small ones as possible: exactly 200 − L small.

要让大蜡烛最多，小蜡烛只买到凑够 200 个。

Solution · 解析

  1. Write the conditions: Budget: 4.90s + 11.60L ≤ 2,200. Count: s + L ≥ 200.
  2. Use the fewest small candles: Take s = 200 − L: 4.90(200 − L) + 11.60L ≤ 2,200.
  3. Solve: 980 − 4.90L + 11.60L ≤ 2,200 → 6.70L ≤ 1,220 → L ≤ 182.09…
  4. Round down: Candles are whole: L = 182. Check: 18 small + 182 large = 200 candles costs 88.20 + 2,111.20 = 2,199.40 ≤ 2,200 ✓
Desmos · 图形计算器
14.9x+11.6y<=2200
2x+y>=200
3x>=0

Shaded = possible purchases (x small, y large). Highest point ≈ (17.9, 182.1) → at most 182 large.

Answer: 182. The owner can buy at most 182 large candles. Takeaway. For a maximum, push the other quantity to its smallest allowed value, solve, and round down. 求最大：让另一个量取最小，再向下取整。

Idea · 思路

“The minimum value of x is …” means every x is at least that value.

Solution · 解析

  1. “12 less than 6 times n” = 6n − 12.
  2. Minimum → x ≥ 6n − 12.
最小值是 m → x ≥ m；“比 6n 少 12” 是 6n − 12。

Why not the others · 错误选项

A ✗ x ≤ 6n − 12 would make 6n − 12 the maximum.
C ✗ 12 − 6n is “6 times n less than 12”, and ≤ describes a maximum.
D ✗ 12 − 6n reverses the subtraction.

Answer: B.

Summary

What to remember about inequalities不等式要点

01 · 不等号方向

“At most / no more than / maximum / budget” → ≤. “At least / minimum” → ≥.

02 · 最小值表述

“The minimum value of x is m” → x ≥ m.

03 · 负数与变号

Solve like an equation; flip the sign when multiplying or dividing by a negative.

04 · 整数边界

Whole-number answers: round down for a greatest value, up for a least value.

05 · 检验每个条件

A point solves a system only if it makes every inequality true.
