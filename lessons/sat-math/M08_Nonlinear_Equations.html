Four mini examples 四个小例子

EquationUndo with …Steps

Rule: first get the hard part alone. In 3√x + 1 = 13: subtract 1, divide by 3 → √x = 4 → x = 16.

每种“难的部分”都有对应的逆运算：平方 ↔ 开方（±），根号 ↔ 平方，绝对值 → 分两种情况，分母 → 两边乘分母。先把它单独放在一边，再去掉。

注意：√25 只等于 5；但方程 x² = 25 有两个解 ±5。

Concept

Check for fake (extraneous) solutions · 检验增根

Example: √x + 6 = x

  1. Square both sides: x + 6 = x2.
  2. Make one side 0: x2 − x − 6 = 0.
  3. Factor: (x − 3)(x + 2) = 0 → x = 3 or x = −2.
  4. Check in the original:
    x = 3: √9 = 3 ✓
    x = −2: √4 = 2, but the right side is −2 ✗
  5. Only x = 3 is a solution; −2 is extraneous.

两边平方会把“负的那一边”也变成正的，所以可能多出假解。根号的结果不能是负数，必须代回原方程检验。

Common mistakes 常见错误

❌ √x2 + 9 = x + 3√16 + 9 = 5, but 4 + 3 = 7. You cannot take the root term by term. 根号不能拆开逐项开方。

❌ (x + 1)2 = 16 → x + 1 = 4 → x = 3 onlyAlso x + 1 = −4 → x = −5. 别漏掉负根。

❌ |x| = −4 → x = ± 4An absolute value is never negative: no solution. 绝对值不能等于负数 → 无解。

✅ 6x − 1 = x → x = 3 or x = −2, then check x − 1 ≠ 0Both work: 62 = 3, 6−3 = −2. 分式方程要检查分母不为 0。

平方、开方、去分母之后都要回到原方程验算一次。

Concept

Where a line meets a curve · 直线与曲线的交点

Example 例子

Solve the system y = x2 and y = x + 2.

  1. Both equal y, so set them equal: x2 = x + 2.
  2. One side 0: x2 − x − 2 = 0.
  3. Factor: (x − 2)(x + 1) = 0 → x = 2 or x = −1.
  4. Find y with the simpler equation y = x + 2: (2, 4) and (−1, 1).

Desmos: type y=x^2 and y=x+2, click the two crossing points.

两个式子都等于 y，就令它们相等，得到一个二次方程；解出 x 后再代回求 y。Desmos 上两图像的交点就是方程组的解。

How many intersections? 有几个交点

After substituting you get a quadratic. Its discriminant b2 − 4ac tells the number of intersection points.

  • y = x2, y = 2x − 1 → x2 − 2x + 1 = 0 → 4 − 4 = 0 → exactly one point (1, 1) (the line just touches).
  • y = x2, y = x − 5 → x2 − x + 5 = 0 → 1 − 20 < 0 → no intersection.

代入后得到二次方程：判别式 > 0 两个交点，= 0 一个交点（相切），< 0 没有交点。“exactly one solution” 就是判别式 = 0。

Key facts

One rule for each kind of equation每种方程一条规则

x2 = k
平方方程
x = ±√k (two answers if k > 0; none if k < 0)
例：x² = 9 → x = ±3；x² = 0 只有 0；x² = −9 无实数解。
|A| = k
绝对值＝距离
A = k or A = −k (none if k < 0)
例：|x − 2| = 3 → x − 2 = ±3，得 x = 5 或 −1。
√A = k
根式方程
square both sides: A = k2; then check the answer
先要求 k ≥ 0，再平方。例：√x + 3 = 4 → x + 3 = 16，x = 13。代回原式验算。
aB = x
分式方程
multiply by B: a = xB; check that B ≠ 0
分母不可为零。例：6/x = 2 → x = 3；代回 6/3 = 2。
ax3 = k
立方方程
divide, then take the cube root
例：2x³ = 54 → x³ = 27 → x = 3；立方根不另加 ±。
Product = 0
零乘积性质
(x + 2)(x − 5)(x + 9) = 0 → each factor can be 0
任一因式为零即可：x = −2、5、−9。若乘积不为 0，不能这样拆。
Line & curve
直线与曲线联立
set the two expressions equal; solve; then find y
例：y = x² 与 y = x + 2 → x² − x − 2 = 0，交点 (−1, 1)、(2, 4)。
Exactly one intersection
恰有一个交点
after substituting, the quadratic has discriminant 0
对直线与抛物线，代入后仍为二次方程时，Δ = 0 表示相切。例：y = x² 与 y = 0。

Squaring both sides can create “fake” solutions. Always check your answer in the original equation. 两边平方可能产生增根，一定代回原方程检验。

How to approach it

Steps

1

Isolate the hard part

Get the square, root, absolute value, or fraction alone on one side. 先把平方/根号/绝对值/分式单独放在一边。

2

Undo it

Square root (±), square, split into two cases, or multiply by the denominator. 用对应的逆运算去掉它。

3

Solve and check

Usually a linear or quadratic equation remains. Check in the original; answer exactly what is asked (x − 1, 6x, the positive solution). 解出后代回检验，回答所问。

Desmos is very strong here: type the two sides as y=55/(x+6) and y=x; the intersections are the solutions. For one equation, you can also type it directly, e.g. |x-5|=10, and Desmos draws vertical lines at the solutions. Desmos：左右两边各画一个图，交点就是解；也可以直接输入方程。

Summary

What to remember about nonlinear equations非线性方程要点

01 · 平方方程

x2 = k → ±√k; x2 equal to a negative number → no real solution.

02 · 绝对值

|A| = k → A = k or A = −k.

03 · 去根号与分母

Square both sides to remove a root; multiply by the denominator to clear a fraction. Then check.

04 · 直线与曲线

Line–curve system: set equal and solve; “exactly one intersection” → discriminant 0.

05 · 核对所求

Answer what is asked: the positive solution, x − 1, 6x, …
