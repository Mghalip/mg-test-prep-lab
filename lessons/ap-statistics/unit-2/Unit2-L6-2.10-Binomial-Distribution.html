Binomial Random Variable 二项随机变量

Definition定义
A binomial random variable X is a discrete random variable that counts the number of successes in n repeated independent trials that have only two possible outcomes (success or failure), with probability of success p and probability of failure 1 − p.
二项随机变量 X：在 n 次独立重复试验中，“成功”的次数。每次试验只有两种结果（成功/失败），成功概率为 p，失败概率为 1 − p。
B

Binary

Each trial: success or failure. 两种结果

I

Independent

Knowing one trial's result tells nothing about another. 相互独立

N

Number

The number of trials n is fixed in advance. 次数固定

S

Same p

Same probability of success p on every trial. 概率相同

📝 Example 2 · 例题★★★★LO 2.10.A · Skill 4.B

Binomial setting or not? 是不是二项？说明理由

aBlood type. Each child of a particular set of parents has probability 0.25 of type O blood, independently. The parents have 5 children. X = number with type O.
Binary type O / not ✓ · Independent genes inherited independently ✓ · Number n = 5 ✓ · Same p 0.25 ✓ → Binomial
bAces. Shuffle a deck. Turn over the first 10 cards, one at a time. X = number of aces.
Independent? No — if the 1st card is an ace, the 2nd is less likely to be an ace (no replacement). → Not binomial
cUntil an ace. Turn over the top card, put it back, shuffle, repeat until you get an ace. X = number of cards turned.
Number? No — the number of trials isn’t fixed in advance. → Not binomial
🔑 Check Binary · Independent · Number · Same p.
💡 To show it is not binomial, one failed condition is enough.

Mean and Standard Deviation of a Binomial 二项分布的均值与标准差

Formulas公式
If X is binomial with n trials and success probability p: μ_{X} = np    σ_{X} = √(np(1 − p))
二项随机变量的均值 μ = np，标准差 σ = √(np(1 − p))。（这些公式在 AP 公式表上。）

📝 Example 3 · 例题★★★★EK 2.10.B.1 · 2.10.C.1

Bottled water or tap water? 瓶装水还是自来水？

In a taste test, each of 21 students tries to identify which of 3 cups holds bottled water. If they are all just guessing, p = 1/3. Let X = number who guess correctly.

aCalculate and interpret μ_{X}.
μ = 21(1/3) = 7. If many, many classes of 21 students all guessed, the average number of correct identifications would be about 7.
bCalculate and interpret σ_{X}.
σ = √(21 · 1/3 · 2/3) ≈ 2.16. The number of correct guesses typically varies from the mean of 7 by about 2.16 students.
c⭐ Challenge: 11 students got it right. Is that convincing evidence that they are not just guessing? (P(X ≥ 11) ≈ 0.056)
P(X ≥ 11) ≈ 0.056 — not tiny (about 1 in 18), so 11 correct is not very convincing evidence; it could plausibly happen by guessing.
🔑 X ~ binomial(n = 21, p = 1/3).

Binomial Probability Function 二项概率函数

Formula公式
The probability that a binomial random variable X has exactly x successes in n independent trials, with success probability p, is P(X = x) = C(n, x) · pˣ · (1 − p)ⁿ⁻ˣ for x = 0, 1, 2, …, n. Here C(n, x) = n! / (x!(n − x)!) is the number of ways to arrange x successes among n trials.
二项随机变量恰好有 x 次成功的概率 = C(n, x) · pˣ · (1 − p)ⁿ⁻ˣ。C(n, x)（也写作 ₙCₓ）是在 n 次中安排 x 次成功的方法数。

Use the formula 用公式计算

Blood type: n = 5 children, p = 0.25.

aFind P(X = 1).
C(5,1)(0.25)¹(0.75)⁴ = 5(0.25)(0.3164) ≈ 0.3955
bShould the parents be surprised if more than 3 children have type O?
P(X > 3) = P(4) + P(5) = 0.0146 + 0.0010 ≈ 0.0156. Yes — that happens only about 1.6% of the time.
🔑 X ~ binomial(5, 0.25).

📝 Example 7 · 例题★★★★EK 2.10.C.1 · 2.10.E.1 · Skill 4.B

"Draw a three, get it free" 抽到 3 就免单

A restaurant’s computer simulates drawing one card from a standard deck for each customer; a three means a free lunch (p = 4/52 = 1/13). On the first day, 250 customers ordered lunch.

aFind P(fewer than 10 customers win).
P(X < 10) = P(X ≤ 9) = binomcdf(250, 1/13, 9) ≈ 0.006
bOnly 9 customers won. Is this convincing evidence that the program is flawed?
Yes. If the program worked properly, there is only a 0.006 probability that fewer than 10 of 250 customers would win — very unusual by chance alone.
cFind the expected number of winners per day and σ.
μ = 250/13 ≈ 19.2 winners; σ = √(250 · 1/13 · 12/13) ≈ 4.21
🔑 X ~ binomial(n = 250, p = 1/13).

2.10 · AP Exam Tips

Common mistakes 常见错误

✗ Mistake 1

Calculator-speak only

"binomcdf(250, 1/13, 9)" alone isn't enough. Define X, name the distribution, give n and p.

只写计算器语言不够，要写明 X ~ B(n, p)。

✗ Mistake 2

"At least" off by one

P(X ≥ 3) = 1 − P(X ≤ 2), not 1 − P(X ≤ 3).

“至少”时注意减 1。

✗ Mistake 3

Forgetting C(n, x)

pˣ(1 − p)ⁿ⁻ˣ is the probability of one arrangement — multiply by the number of arrangements.

别忘了乘排列数。

✗ Mistake 4

Ignoring "fixed n"

"Until the first success" has no fixed n → not binomial.

“直到成功为止”不是二项。

📝 Example 8 · 例题★★★★EK 2.10.A–E

Three-point shots 三分球（mini-FRQ）

A player makes 30% of her three-point shots. In a game she takes 10 three-point shots. Assume shots are independent. Let X = number made.

aJustify that X is binomial.
Binary: make/miss · Independent: given · Number: n = 10 · Same p: 0.30 each shot.
bFind P(X = 3).
C(10,3)(0.3)³(0.7)⁷ = 120(0.027)(0.0824) ≈ 0.267
cFind P(X ≥ 3).
1 − P(X ≤ 2) = 1 − binomcdf(10, 0.3, 2) ≈ 0.617
dCalculate and interpret μ and σ.
μ = 10(0.3) = 3; σ = √(10 · 0.3 · 0.7) ≈ 1.45. Over many games with 10 attempts, she makes about 3 threes on average, typically varying from 3 by about 1.45.
🔑 X ~ binomial(n = 10, p = 0.3).

Which is binomial?

Which random variable has a binomial distribution?
  • (A) The number of rolls of a die until a 6 appears
  • (B) The number of heads in 20 tosses of a fair coin
  • (C) The number of girls chosen when 4 students are picked without replacement from a class of 6 girls and 6 boys

(B): heads/tails · independent · n = 20 · p = 0.5 → binomial.

60% of students at a school have a library card. A random sample of 20 students is selected (from a large school). What are the mean and standard deviation of the number with a library card?

The 10% Condition 10% 条件

10% condition10% 条件
Real sampling is done without replacement, which breaks independence. But when the sample is small compared with the population — n < 10% of N — the count of successes is approximately binomial.
实际抽样多为不放回，严格来说不独立。但当样本量小于总体的 10%（n < 0.10N）时，成功次数近似服从二项分布。

📝 Example 11 · 例题★★★★TPS 6.3 · EK 2.10.E.1

Teens with debit cards 借记卡

Suppose exactly 12% of U.S. teens aged 14–18 have a debit card. A random sample of 500 teens is selected. Let X = number with a debit card.

aExplain why X can be modeled as binomial even though the sample is taken without replacement.
500 is far less than 10% of all U.S. teens aged 14–18, so the trials are approximately independent → X ≈ binomial(500, 0.12).
bFind the probability that 50 or fewer teens in the sample have a debit card.
P(X ≤ 50) = binomcdf(500, 0.12, 50) ≈ 0.0932
cFind μ and σ.
μ = 500(0.12) = 60; σ = √(500 · 0.12 · 0.88) ≈ 7.27
🔑 n = 500, p = 0.12.

"At least" with a calculator

X is binomial with n = 20 and p = 0.6. Which expression gives P(X ≥ 15)?
  • (A) binomcdf(20, 0.6, 15)
  • (B) 1 − binomcdf(20, 0.6, 15)
  • (C) binompdf(20, 0.6, 15)
  • (D) 1 − binomcdf(20, 0.6, 14)
  • (E) 1 − binompdf(20, 0.6, 14)

“At least 15” = 15, 16, …, 20. Its complement is X ≤ 14.

P(X ≥ 15) = 1 − binomcdf(20, 0.6, 14) ≈ 1 − 0.874 = 0.126 → (D).

Exit ticket 🎟️ 离堂小测

10% of a factory’s light bulbs are defective. A random sample of 8 bulbs is selected (from a very large batch). Let X = number defective.

1Is X binomial? Why?
Yes — defective/not; independent (large batch); n = 8; p = 0.1.

1 − P(X = 0) = 1 − 0.9⁸ ≈ 0.570

Behind the Formula · 公式背后的逻辑
3 min · derivation optional

A binomial count is a sum把计数拆成 0 和 1

Let Iᵢ = 1 for a success and 0 for a failure. If P(success) = p, then Iᵢ² = Iᵢ.

\operatorname{E}(I_i)=p\qquad\operatorname{Var}(I_i)=\operatorname{E}(I_i^2)-[\operatorname{E}(I_i)]^2=p-p^2

For n independent trials with the same p, X = I₁ + ⋯ + Iₙ. Expectations add; independence lets variances add.

\operatorname{E}(X)=np\qquad\operatorname{Var}(X)=np(1-p)
\operatorname{SD}(X)=\sqrt{np(1-p)}

二项公式来自“成功记1、失败记0”。相加的是方差，标准差最后才开平方。

Check your understanding · n = 100, p = 0.20: mean and SD?

Mean = 20 successes; variance = 16; SD = 4 successes.
